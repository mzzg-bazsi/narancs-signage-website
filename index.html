Narancs Signage is a complete signage system: an admin panel, a player that runs on any ARM or x86 box, and installers for Linux, Windows, macOS and Raspberry Pi. Slideshows, calendars, forms, touch menus — managed from one place, running even when the network is down. Programmed entirely by Claude, Anthropic's AI.

Branding

10 built-in themes in dark and light mode, custom colours and fonts, shareable theme files, logo watermark and header bar. A different theme per screen.

Emergency alerts

An instant full-screen message on all or selected screens, with templates and expiry.

Roles and API

Administrator, editor and viewer roles, plus API keys so other systems can send alerts or content.

Scheduling

Playlists per screen by day, time window and date range. Scheduled screen off turns the monitor off too (DPMS).

Remote control

Live screenshot of the real display, identify, previous/next, reload, restart the player or reboot the device — from the admin.

Works offline

The player caches its configuration and media and keeps running if the server goes down.

Polished kiosk

Boot splash with a progress bar instead of console text, touch or mouse mode per screen, no translate pop-ups.

Up and running in minutes

1 Server Ubuntu / Debian, amd64 or arm64 · macOS: same without sudo

curl -fsSL https://github.com/mzzg-bazsi/narancs-signage/releases/latest/download/install.sh | sudo bash

Installs Node.js, a systemd service and daily backups. Open http://SERVER-IP:8080/admin/ and create your account.

2 Each display Ubuntu Server or Raspberry Pi OS Lite

curl -fsSL http://SERVER-IP:8080/install-player.sh | sudo bash

Reboot, then enter the 6-digit code shown on the screen under Screens → New screen. No install? Open /player/ in any browser.

Windows — a setup wizard for the server, a kiosk display, or both on one PC. Node.js is included; the display-only mode turns the PC into a kiosk that signs in by itself.
Download for Windows

Using a Raspberry Pi? Flash a ready-made image instead – it installs everything on the first start, as a display, a server, or both in one.
