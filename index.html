Narancs Signage is a complete signage system: an admin panel, a player that runs on any ARM or x86 box, and one-command installers for Ubuntu Server. Slideshows, calendars, forms, touch menus — managed from one place, running even when the network is down. Programmed entirely by Claude, Anthropic's AI.

Up and running in minutes

1 Server Ubuntu 22.04 / 24.04, amd64 or arm64

git clone https://github.com/mzzg-bazsi/narancs-signage.git
cd narancs-signage
sudo ./install/install-server.sh

Installs Node.js, a systemd service and daily backups. Open http://SERVER-IP:8080/admin/ and create your account.

2 Each display Ubuntu Server or Raspberry Pi OS Lite

curl -fsSL http://SERVER-IP:8080/install-player.sh | sudo bash

Reboot, then enter the 6-digit code shown on the screen under Screens → New screen. No install? Open /player/ in any browser.
