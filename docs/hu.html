Narancs Signage dokumentáció

Minden, ami a Narancs Signage telepítéséhez, üzemeltetéséhez és használatához kell. A Narancs Signage egy teljes, saját szerveren futó digitális kijelzőrendszer.

A rendszer három részből áll:

  • Szerver: kis Node.js program SQLite adatbázissal. Ez szolgálja ki az admin felületet, tárolja a tartalmakat és a médiafájlokat, és valós időben küldi a változásokat a kijelzőknek.
  • Admin felület: webes alkalmazás a /admin/ címen, itt kezeled a képernyőket, lejátszási listákat, tartalmakat, az arculatot és a vészjelzéseket.
  • Lejátszó: webes alkalmazás a /player/ címen, teljes képernyőn fut minden kijelzőn. A lejátszó telepítője bármelyik Ubuntu Servert vagy Raspberry Pi-t lezárt kioszkká alakítja, ami ezt futtatja.

Követelmények

RészKövetelmény
SzerverUbuntu Server 22.04 / 24.04 (amd64 vagy arm64). Több tucat kijelzőhöz is elég 1 processzormag és 1 GB RAM; a tárhely a médiafájlok méretétől függ. Node.js ≥ 22.13 (a telepítő a Node.js 24-et teszi fel).
KijelzőUbuntu Server 22.04 / 24.04 vagy Raspberry Pi OS Lite (arm64, armhf, amd64). Raspberry Pi 4/5 vagy bármilyen mini PC, HDMI-n csatlakozó monitor vagy tévé; interaktív tartalmakhoz érintőképernyő.
HálózatA kijelzőknek HTTP-n el kell érniük a szervert (alapból a 8080-as porton). Az időjáráshoz, az RSS-hez és az iCal naptárakhoz a szervernek internet kell.
Csak böngészőBármely modern böngésző megnyithatja a /player/ címet telepítés nélkül (okostévé, tablet, signage stick).

Gyors kezdés

  1. Telepítsd a szervert egy Ubuntus / Debianos gépre (vagy Macre, sudo nélkül): 
    curl -fsSL https://github.com/mzzg-bazsi/narancs-signage/releases/latest/download/install.sh | sudo bash
  2. Nyisd meg az admin felületet a telepítő által kiírt címen (http://SZERVER-IP:8080/admin/), válassz nyelvet, és hozd létre az admin fiókot. Egy alap lejátszási lista minta tartalmakkal automatikusan létrejön.
  3. Telepítsd a lejátszót minden kijelző gépre: 
    curl -fsSL http://SZERVER-IP:8080/install-player.sh | sudo bash
  4. Indítsd újra a kijelzőt. Megjelenik rajta egy 6 jegyű párosító kód.
  5. Párosítsd az admin felületen a Képernyők → Új képernyő menüben. A képernyő azonnal elkezdi játszani az alap listát.

Minden egy gépen? Előbb a szervert telepítsd, utána ugyanarra a gépre a lejátszót, http://localhost:8080 címmel.

A szerver telepítése

Az egysoros telepítő letölti a legfrissebb kiadást a GitHubról, és lefuttatja a szerver telepítőt. A kapcsolók a bash -s -- után jönnek:

curl -fsSL https://github.com/mzzg-bazsi/narancs-signage/releases/latest/download/install.sh | sudo bash -s -- [--port 8080] [--data /var/lib/narancs-signage]

Klónozott projekt mappából ugyanez: sudo ./install/install-server.sh [kapcsolók].

macOS: ugyanez a parancs sudo nélkül. Ha kell, Homebrew-val telepíti a Node.js-t, és bejelentkezéskor elindítja a szervert (LaunchAgent). Adatok: ~/Library/Application Support/Narancs Signage/data, napló: ~/Library/Logs/narancs-signage.log. Más rendszeren: Docker.

KapcsolóAlapértékLeírás
--port8080A szerver HTTP portja.
--data/var/lib/narancs-signageAz adatbázis és a médiafájlok helye.

A telepítő:

  • feltelepíti a Node.js 24-et a NodeSource-ból, ha nincs megfelelő verzió,
  • a programot a /opt/narancs-signage mappába másolja, és létrehoz egy signage rendszerfelhasználót,
  • létrehozza és elindítja a narancs-signage systemd szolgáltatást,
  • telepíti a signage-backup parancsot és a napi mentést hajnali 3-kor,
  • megnyitja a portot a tűzfalon, ha az ufw aktív.

Újrafuttatva frissíti a programot, az adatok megmaradnak.

Első belépés

Az első megnyitáskor az admin felület megkérdezi a nyelvet (angol vagy magyar), és létrehozod az első admin fiókot. Ekkor egy alap lejátszási lista is készül minta tartalmakkal (hirdetmény, óra és időjárás, kártyák, naptár, interaktív menü, elégedettségi kérdőív, visszaszámlálás), így egy frissen párosított képernyőn rögtön látszik valami. Ezeket szabadon szerkesztheted vagy törölheted.

HTTPS és fordított proxy

A szerver sima HTTP-t beszél. HTTPS-hez tegyél elé egy fordított proxyt. Caddy-vel (automatikus tanúsítvánnyal):

signage.example.com {
  reverse_proxy localhost:8080
}

nginx esetén kapcsold ki a válasz pufferelést, mert a kijelzők Server-Sent Events kapcsolaton kapják a változásokat:

location / {
  proxy_pass http://127.0.0.1:8080;
  proxy_buffering off;
  proxy_read_timeout 1h;
  proxy_set_header Host $host;
}

Docker

Kész image amd64-re és arm64-re (bármilyen Linux, NAS, Synology, Unraid). Az adatok a /data kötetben vannak:

docker run -d --name narancs-signage -p 8080:8080 -v narancs-signage:/data -e TZ=Europe/Budapest --restart unless-stopped ghcr.io/mzzg-bazsi/narancs-signage:latest

Vagy a repóban lévő docker-compose.yml-lal: docker compose up -d. Frissítéshez töltsd le az új image-et, és hozd létre újra a konténert; az adatok a kötetben maradnak.

Futtatás telepítő nélkül

Bármely gépen, ahol van Node.js ≥ 22.13 (macOS, Windows, Linux), közvetlenül is futtatható; nincs telepítendő függőség:

cd server
npm run dev

A kijelző telepítése

A kijelzőhöz csatlakoztatott gépen egyetlen parancsot kell futtatni. Az admin felület a Képernyők → Új képernyő menüben másolható formában mutatja.

curl -fsSL http://SZERVER-IP:8080/install-player.sh | sudo bash

A kapcsolók a -s -- után jönnek, például:

curl -fsSL http://SZERVER-IP:8080/install-player.sh | sudo bash -s -- --nightly-reboot --rotate 90
KapcsolóLeírás
--nightly-rebootAz eszköz minden éjjel 4:30-kor újraindul.
--rotate 90|180|270Hardveres képforgatás. (Szoftveres forgatás képernyőnként az admin felületen is állítható.)
--gpu / --no-gpuA grafikus gyorsítás kényszerített be- vagy kikapcsolása. Alapból automatikus: virtuális gépen és GPU nélkül szoftveres megjelenítés.
--user NÉVA kioszk felhasználó neve (alap: kiosk).
--uninstallA lejátszó eltávolítása (kioszk felhasználó, automatikus belépés, szkriptek, bootkép).
--purgeEltávolítás a Chromiummal és a grafikus csomagokkal együtt.

Mit állít be?

  • Minimális X11 környezetet ablakkezelő és asztal nélkül, és kioszk módú Chromiumot. Ha a Chromium összeomlik, magától újraindul.
  • Automatikus belépést a tty1-en egy külön kiosk felhasználóval.
  • Kikapcsolja a képernyővédőt és az energiatakarékosságot; a monitort a képernyő be/kikapcsolási ütemezése szerint kapcsolja (DPMS).
  • Bootképet logóval és folyamatjelzővel a konzolszöveg helyett, újraindításkor és leállításkor is (Plymouth, csendes GRUB).
  • A signage-agent szolgáltatást, amivel az admin felületről újraindítható a lejátszó vagy az egész eszköz.
  • A signage-diag hibakereső parancsot.

A beállítások a /etc/narancs-signage/player.conf fájlban vannak (szervercím, eszközazonosító, Chromium útvonala, forgatás, extra Chromium kapcsolók). Módosítás után indítsd újra a lejátszót az admin felületről, vagy indítsd újra az eszközt.

Párosítás

Újraindítás után a kijelzőn megjelenik egy 6 jegyű kód és a szerver címe. Az admin felületen nyisd meg a Képernyők → Új képernyő menüt, írd be a kódot, adj nevet a képernyőnek, és válassz lejátszási listát. A képernyő néhány másodpercen belül elindul. A 24 órája nem jelentkező, párosítatlan eszközök automatikusan törlődnek.

Telepítés nélkül

Nyisd meg a http://SZERVER-IP:8080/player/ címet bármely böngészőben (okostévé, kioszk módú tablet, signage stick). Ugyanúgy párosító kódot mutat, mint a telepített lejátszó. A távoli újraindításhoz és a monitor időzített kikapcsolásához telepített lejátszó kell, minden más ugyanígy működik.

Eltávolítás

curl -fsSL http://SZERVER-IP:8080/install-player.sh | sudo bash -s -- --uninstall

Utána az admin felületen is töröld a képernyőt. Újratelepítéshez egyszerűen futtasd újra a telepítő parancsot.

Az admin felület

Az admin felület asztali gépen és mobilon is működik, világos és sötét módban. A legtöbb változás mentés után azonnal megjelenik a képernyőkön. A szerkesztőkben a Ctrl/⌘ + S ment.

Irányítópult

Online képernyők, tartalmak és listák száma, az elmúlt 7 nap érintései és űrlap beküldései, aktivitás grafikon, a legnézettebb tartalmak, a legutóbbi beküldések, az aktív vészjelzések és a tárhely. Gombok az összes képernyő újratöltéséhez és azonosításához.

Képernyők

Minden párosított képernyő egy kártya: állapot (online/offline), beviteli mód (érintés vagy egér), mi játszik éppen, lejátszási lista, felbontás, utolsó jelentkezés. Az Élő előnézet kapcsolóval minden képernyő képe élőben látszik.

Lejátszási listák

A lejátszási lista tartalmak sorrendje. A sorokat húzással rendezheted. Minden elemnél beállítható:

  • a megjelenési idő másodpercben (üresen: a tartalom saját ideje),
  • egy be/ki kapcsoló az ideiglenes kihagyáshoz,
  • érvényességi dátumok (-tól, -ig), például egy akció, ami magától eltűnik.

Az elemek közötti áttűnés lehet áttűnés, becsúszás, nagyítás, felúszás vagy semmi. A jobb oldali élő előnézet pontosan úgy játssza a mentett listát, ahogy a képernyők.

Saját sablonok: bármely tartalom vagy lejátszási lista Exportálás gombja egy .narancs.json fájlt tölt le. Benne van a tartalom, minden, amire hivatkozik (menü- és kártyacélok, zónák), az űrlapok szerkezete és a képek (legfeljebb 40 MB). Az űrlap-beküldések, a saját naptáresemények és az iCal linkek nem kerülnek bele. A Sablonok oldal Importálás fájlból gombjával bármely Narancs Signage rendszerbe betölthető; a fájlt előbb ellenőrzi (ismert tartalomtípusok, érvényes hivatkozások, engedélyezett médiatípusok, méretkorlátok), és egy lépésben importálja — ha valami hibás, semmi nem jön létre.

A formátum egyszerű JSON ("format": "narancs-template", "version": 1): a tartalmak nevekkel hivatkoznak egymásra (s1, f1, c1, m1), a szövegek lehetnek kétnyelvűek ({"en": "…", "hu": "…"}), a {{org_name}}, {{city}} és {{date+N}} helyőrzőket importáláskor tölti ki.

Közösségi galéria

A Sablonok oldal Közösségi galéria füle a narancs-signage-templates repó sablonjait mutatja — a tíz beépített sablont és mindent, amit a felhasználók beküldenek — élő előnézettel, szerzővel, licenccel, Telepítés és Letöltés gombbal. A galériát a szerver tölti le (internet kell hozzá), és 10 percig tárolja. Saját galériához a SIGNAGE_GALLERY környezeti változót kell beállítani.

Sablon nyelve: a Sablonok oldal tetején lévő választó dönti el a kétnyelvű sablonoknál az előnézet és a telepített tartalom nyelvét, a galéria pedig az azon a nyelven elérhető sablonokat mutatja.

Sablon beküldése:

  1. Nyiss meg egy tartalmat vagy lejátszási listát → Exportálás → adj meg nevet, leírást és kategóriát → Beküldés a galériába. A fájl letöltődik, és megnyílik a galéria beküldő űrlapja a GitHubon (ingyenes GitHub fiók kell hozzá).
  2. Húzd a letöltött .narancs.json fájlt a Template file mezőbe, válaszd ki a nyelveket és a licencet (CC0 vagy CC BY), és küldd el az űrlapot.
  3. Egy robot ugyanazzal az ellenőrzéssel vizsgálja meg a sablont, amit a Narancs Signage is használ, és hozzászólásban válaszol: vagy megnyitja a pull requestet, vagy leírja, mit kell javítani (az issue szerkesztése után újra ellenőrzi).
  4. Jóváhagyás után a sablon minden Narancs Signage admin felületén megjelenik.

Médiatár

Képek (JPG, PNG, WebP, GIF), videók (MP4, WebM) és PDF-ek feltöltése húzással. Egy fájl legfeljebb 2 GB lehet (MAX_UPLOAD_MB). Minden fájlnak van közvetlen linkje; a lejátszók letöltik és eltárolják őket az offline működéshez.

Naptárak

Hozz létre naptárakat egy színnel (a téma valamelyik színe vagy egy előre megadott szín), és vegyél fel eseményeket kézzel, vagy importálj egy Google, Outlook vagy bármilyen iCal (.ics) linket. Az importált naptárak 15 percenként frissülnek, a Frissítés gombbal azonnal. Egész napos események is lehetnek. Az ismétlődő események mindkét irányban működnek: az importált naptárak ismétlődési szabályait kibontja (napi, heti, havi — pl. „minden hónap utolsó péntekje” —, éves, kihagyott és áthelyezett alkalmakkal), a saját események pedig ismétlődhetnek naponta, hetente, havonta vagy évente, opcionális befejező dátummal.

Űrlapok

Érintőképernyős űrlapok kérdőívekhez, jelentkezésekhez, vendégregisztrációhoz. Indulhatsz sablonból (elégedettségi kérdőív, kapcsolatfelvétel, vendégregisztráció) vagy üresen.

Mezőtípusok: rövid szöveg, hosszú szöveg, e-mail, telefonszám, szám, legördülő lista, választógombok, jelölőnégyzet, csillagos értékelés, elégedettség (smiley). Bármely mező lehet kötelező. A kijelzőn szöveges mezőkhöz virtuális billentyűzet (angol vagy magyar kiosztás) jelenik meg, ha a képernyőn be van kapcsolva.

A beküldések az űrlap alatt látszanak, azzal együtt, melyik képernyőről jöttek; CSV-be exportálhatók.

Arculat

  1. Téma: 10 beépített téma (Narancs, Óceán, Erdő, Éjféli lila, Bordó, Fekete-arany, Neon, Tiszta világos, Vállalati kék, Pasztell). Mindegyik beállítja a színeket, betűtípusokat és a lekerekítést; utána bármelyik szín, a szöveg és a címek betűtípusa és a lekerekítés felülírható.
  2. Szervezet, logó és címek: a szervezet neve, szlogen, logó (átlátszó hátterű PNG vagy SVG ajánlott), logó vízjel valamelyik sarokban, méretével és átlátszatlanságával.
  3. Fejléc sáv: logó, cím, alcím és óra minden képernyő tetején, minden tartalom fölött.
  4. Tartalmak színezése: az új tartalmak alapból a téma színeit használják; az Összes tartalom arculat szerint gomb a régebbi, egyedi színű tartalmakat is átszínezi. A képek és videók nem változnak.

A változások azonnal látszanak az előnézetben, és mentés után kerülnek ki a képernyőkre. Egy képernyő eltérő témát is használhat (Képernyők → Szerkesztés → Megjelenés); a logó és a fejléc globális marad.

Vészjelzés

Azonnali teljes képernyős üzenet minden vagy csak a kiválasztott képernyőkön. Megadható a cím, az üzenet, a szint (információ, figyelmeztetés, veszély, siker) és a lejárat percben (vagy lejárat nélkül). Sablonok: tűzriadó, evakuálás, rövid szünet, gratuláció. Az aktív jelzések listájában egy gombbal leállíthatók; a képernyők a lejáratig vagy a leállításig mutatják.

Riportok (lejátszási igazolás)

A Riportok menüben látod, mi, hol és hányszor ment le: megjelenések és érintések egy időszakra (7 nap, 30 nap, ez a hónap vagy tetszőleges dátumok), ha kell, egy képernyőre szűrve, napi diagrammal, tartalom és képernyő szerinti toplistával. A CSV letöltése minden eseményt exportál (időpont, képernyő, tartalom, típus, megjelenés/érintés) — például hirdetőknek. A kijelzők minden megjelenést és érintést rögzítenek; az adatok 90 napig maradnak meg.

Felhasználók, szerepkörök és API kulcsok

SzerepkörMit tehet
AdminisztrátorMindent, beleértve a felhasználókat, API kulcsokat, a nyelvet, az arculatot, a képernyők párosítását és törlését, az eszközök újraindítását és a mentést.
SzerkesztőTartalmak, lejátszási listák, média, naptárak, űrlapok, képernyő beállítások és parancsok (újraindítás kivételével), képernyőkép, vészjelzés, riportok.
MegtekintőMindent lát, semmit nem módosíthat (csak a saját jelszavát).

Az API kulcsokkal (Beállítások → API kulcsok) más rendszerek — Home Assistant, Zapier, egy szkript — hívhatják az API-t a saját szerepkörükkel: Authorization: Bearer ns_… fejléccel. A kulcs csak létrehozáskor látszik egyszer, a szerver csak a hash-ét tárolja, és bármikor visszavonható. Példa — vészjelzés küldése:

curl -X POST http://SZERVER-IP:8080/api/alerts \
  -H "Authorization: Bearer ns_…" -H "Content-Type: application/json" \
  -d '{"title":"Tűzriadó","message":"Hagyja el az épületet","level":"danger","minutes":30}'

Beállítások

  • Az admin felület, a képernyők és a szerverüzenetek nyelve (angol vagy magyar).
  • Jelszó módosítása, felhasználók szerepkörökkel és API kulcsok (adminisztrátoroknak).
  • Minta tartalmak: az alap minta lista újbóli létrehozása.
  • Rendszer és mentés: adatkönyvtár, futásidő, lejátszó címe, adatbázis letöltése, összes képernyő újratöltése.

A kijelzőn

  • Indulás: bootkép folyamatjelzővel → betöltő kép → tartalom. Ha a szerver nem érhető el, egy állapotképernyő mutatja az okát, és a lejátszó tovább próbálkozik.
  • Offline: a beállítások és az összes médiafájl el van tárolva. Ha a szerver vagy a hálózat leáll, a képernyő tovább játszik, és egy kis „Offline – tárolt tartalom” felirat jelzi.
  • Valós idejű frissítés: a mentett változások, vészjelzések és parancsok másodpercek alatt megérkeznek (Server-Sent Events).
  • Érintés: az interaktív tartalmak (menük, kártyák, űrlapok) reagálnak az érintésre; a képernyőre beállított tétlenségi idő után folytatódik a lejátszás.
  • Egér: nem tablet módban a mutató látszik, amíg mozog az egér, és 3 másodperc után eltűnik.
  • Billentyűzet: → következő, ← előző, I azonosítás.
  • Statisztika: a megjelenések és érintések az irányítópultra kerülnek.

Mentés és visszaállítás

A signage-backup minden éjjel 3-kor teljes mentést készít (adatbázis pillanatkép + média) a /var/backups/narancs-signage/signage-DÁTUM.tar.gz fájlba, és az utolsó 14-et megtartja. Az admin felületről az adatbázis külön is letölthető.

Visszaállítás mentésből:

sudo systemctl stop narancs-signage
cd /var/lib/narancs-signage
sudo rm -f signage.db signage.db-wal signage.db-shm
sudo tar -xzf /var/backups/narancs-signage/signage-20261010-030000.tar.gz
sudo mv backup-20261010-030000.db signage.db
sudo chown -R signage: /var/lib/narancs-signage
sudo systemctl start narancs-signage

A kijelzők frissítése

A lejátszó (böngészős) változásai egy Újratöltés paranccsal jutnak ki a képernyőkre az admin felületről. A kioszk saját változásaihoz (bootkép, ügynök, Chromium kapcsolók) a lejátszó telepítőt újra kell futtatni az eszközön; az eszközazonosító és a párosítás megmarad.

Hibaelhárítás

A kijelzőn a sudo signage-diag kiírja a szerver címét, az eszközazonosítót, hogy elérhető-e a szerver, a párosítás állapotát, a grafikus beállítást és az X napló utolsó sorait. Ugyanez az API diag parancsával távolról is lekérhető; az eredmény a képernyő info.diag mezőjébe kerül.

A kijelző nem mutat párosító kódot
Ellenőrizd a hálózatot és a szerver címét a sudo signage-diag paranccsal. A lejátszó folyamatosan próbálkozik, és néhány sikertelen kísérlet után állapotképernyőt mutat. Ha rossz a szervercím, futtasd újra a telepítőt a helyes címmel.
Fekete vagy egyszínű kép virtuális gépen
Egyes virtuális gépeken (pl. virgl az UTM/QEMU alatt) a 3D gyorsítás képe nem jut ki a kijelzőre. A telepítő felismeri a virtuális gépet, és szoftveres megjelenítést használ; ez a --no-gpu kapcsolóval kényszeríthető.
A képernyő „Offline” az admin felületen
Az eszköz 90 másodperce nem jelentkezett. Ettől még játssza a tárolt tartalmat. Ellenőrizd a hálózatát és az áramellátását; ha újra kapcsolódik, magától frissül.
Egy weboldal nem jelenik meg
Sok oldal tiltja, hogy keretbe ágyazzák (X-Frame-Options / CSP). Használj beágyazást engedő oldalt, egy dashboard „kiosk” vagy „embed” linkjét, vagy képernyőképet.
A videó hang nélkül megy
A telepített lejátszó engedi a hangos automatikus lejátszást. Sima böngészőben a böngésző lenémíthatja, amíg valaki nem kattint az oldalon.
Soha nem jelenik meg az egérmutató
A képernyőn be van kapcsolva a tablet mód (Képernyők → Szerkesztés → Általános). Kapcsold ki, és mozgatáskor látszani fog a mutató.
Az emojik körvonalasak
A lejátszó minden emojit színes emoji betűtípussal rajzol. Futtasd újra a lejátszó telepítőt, hogy a betűtípus csomag felkerüljön.
Elfelejtettem az admin jelszót
A szerveren futtasd: sudo signage-reset-password FELHASZNÁLÓNÉV. Új jelszót ír ki, és mindenhol kijelentkezteti a felhasználót. Felhasználónév nélkül kilistázza a felhasználókat. Dockerben: docker exec -it narancs-signage node src/reset-password.js FELHASZNÁLÓNÉV.

Az admin felület JSON REST API-t használ.
