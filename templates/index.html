    Share your own template

    Built a playlist other businesses could use? Send it in, and after a quick check it appears in every Narancs Signage admin panel.

    Submit a template
    1. Export itIn the admin panel open the content or playlist, then Export → Submit to the gallery.
    2. Attach the fileThe submission form opens on GitHub. Drag the downloaded .narancs.json file into it and send it.
    3. It gets checkedA bot validates it with the same checks the app uses and opens a pull request. After review it is published.
